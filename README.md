
# 🌐 Behruz Portfolio

A modern and responsive portfolio website built to showcase my frontend development skills and projects.

## 🚀 Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript (ES6+)

## ✨ Features

- Fully responsive design
- Dark / Light mode support
- Smooth animations
- Clean UI/UX
- Projects showcase
- Contact section

## 🔗 Live Demo

Vercel link: https://behruzportfolio.vercel.app/

## 📂 Getting Started

Clone the repository:

```bash
git clone https://github.com/behruzrezaie-dev/Portfolio.git
```

Install dependencies:

```bash
npm install
```

Run the app:

```bash
npm run dev
```
